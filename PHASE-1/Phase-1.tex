\bluebigheading{PROPOSAL DESCRIPTION}

\vspace{12mm}

\blueheading{Motivation}

\vspace{1mm}

\instruction{}

\answerbox[8.5cm]{Emergency situations such as road accidents, fires, and medical emergencies require quick and efficient response. In a city, multiple emergencies may occur at the same time while only a limited number of ambulances, emergency vehicles, and response teams are available. In such situations, deciding which emergency should be handled first, which resource should be assigned, and which route should be followed can become difficult if the decisions are made manually.

The proposed Smart Emergency Response System aims to address this problem by developing an algorithm-based system that assists in prioritizing emergencies and allocating available emergency resources efficiently. The project will represent the city road network using a graph, where locations are represented as vertices and roads as weighted edges. Dijkstra's shortest-path algorithm will be used to determine an efficient route between locations.

A priority queue will be used to handle emergencies according to their severity, ensuring that critical cases receive higher priority. Queues, searching, sorting, linked lists/vectors, and hashing can also be incorporated for efficient data management.

The project will be implemented in C++ using Object-Oriented Programming, with classes representing entities such as emergencies, ambulances, hospitals, and locations. The initial system will be a simulation-based prototype designed to demonstrate how DSA and OOP can be applied to a real-world problem.}

\vspace{12mm}

\blueheading{State of the Art / Current solution}

\vspace{1mm}

\instruction{}

\answerbox[7.5cm]{Currently, emergency response generally involves emergency call centers, dispatchers, ambulance services, police, fire departments, and hospitals working together to respond to incidents. Emergency information is received, the incident is assessed, and an available response unit is dispatched to the location.

Modern emergency-management solutions may also use digital maps, GPS, communication systems, and location-based services to support dispatch and navigation. However, the effectiveness of response can still depend on the availability of resources, traffic conditions, communication between agencies, and the decisions made during dispatch.

The proposed project does not attempt to replace existing emergency services. Instead, it focuses on the algorithmic decision-making aspect of emergency response. The system will provide a simulation in which emergencies can be prioritized, available resources can be identified, and routes can be calculated using DSA.

The key gap addressed by the project is the development of an integrated educational prototype that demonstrates how priority queues, graphs, shortest-path algorithms, searching, sorting, and OOP can work together to support emergency-response decisions.}

\vspace{12mm}

\blueheading{Project Approach }

\vspace{1mm}

\instruction{}

\instruction{}

\answerbox[9.1cm]{The project will be developed using a modular and incremental approach. First, the requirements of an emergency-response system will be analyzed and the major entities and operations will be identified. The system will then be designed using Object-Oriented Programming in C++.

Classes such as Emergency, Ambulance, Hospital, Location, and EmergencyResponseSystem will be created to represent the major components. Encapsulation will be used to protect data, while appropriate OOP principles will be applied to make the system modular and maintainable.

Different DSA concepts will be selected according to their practical use. A queue will manage incoming emergency requests, while a priority queue/heap will prioritize emergencies according to severity. The city will be represented as a weighted graph, with locations as vertices and roads as edges. Dijkstra's algorithm will calculate the shortest route between the emergency location and available response resources.

Searching and sorting techniques will be used to locate and organize emergency resources. Linked lists/vectors may be used for dynamic collections, while hashing can provide faster lookup of resources using unique IDs.

The initial platform will be a C++ console-based application developed and tested using a suitable C++ development environment such as Visual Studio Code. The system will use simulated data for emergencies, roads, ambulances, and hospitals.

Development will be incremental: individual data structures and algorithms will first be tested separately and then integrated into the complete emergency-response workflow.}

\blueheading{Assumptions}

\vspace{6mm}

\instruction{}

\answerbox[3.2cm]{The initial system will operate as a simulation using predefined city locations, roads, emergency requests, ambulances, and hospitals. Road distances or travel costs will be represented using numerical weights. Ambulance and hospital availability will be provided as simulated data rather than obtained from real emergency departments. The system assumes that emergency severity can be represented using predefined priority levels. Real-time GPS, traffic information, external APIs, and live hospital data are outside the initial third-semester scope and may be considered for future development.}
